# مذكرتي الذكية PWA

تطبيق عربي متجاوب لحفظ المذكرات، الأماكن، الروابط، والمتتبعات من الجوال أو الكمبيوتر.

الواجهة مصممة بالعربية من اليمين إلى اليسار، بألوان فاتحة وخط عربي جميل، وتعمل كتطبيق ويب قابل للتثبيت على الجوال.

## الميزات

- تصميم عربي فاتح ومتجاوب مع:
  - الجوال الصغير.
  - الجوال العادي.
  - التابلت.
  - شاشة الكمبيوتر.
- حفظ المذكرات اليومية والأفكار والقرارات.
- حفظ الأماكن مع الإحداثيات والصورة والملاحظات.
- حفظ الروابط والمواقع حتى لو كتب المستخدم اسم الموقع فقط.
- متتبعات يومية مثل الوزن والعادات.
- نسخة محلية مؤقتة داخل متصفح الجوال عند الحفظ.
- رفع إلى Supabase عند توفر الاتصال.
- مزامنة من Supabase إلى ملفات Markdown داخل خزنة Obsidian.
- حماية برمز دخول محلي.

## التشغيل المحلي

```bash
python3 app.py
```

بعد التشغيل سيظهر رابطان:

- على نفس الجهاز:
  `http://127.0.0.1:9657`

- على الجوال داخل نفس شبكة Wi-Fi:
  يظهر بجانب `Mobile:` في نافذة التشغيل.

## التثبيت على iPhone

1. افتح رابط الجوال في Safari.
2. اضغط زر المشاركة.
3. اختر: إضافة إلى الشاشة الرئيسية.
4. سيظهر التطبيق باسم: مذكرتي.

## الإعداد

انسخ ملف الإعداد المثال:

```bash
cp config.example.json config.json
```

ثم عدّل:

```json
{
  "vault_path": "~/Documents/الأرشيف الشخصي",
  "port": 9657,
  "passcode": "000000"
}
```

## ربط Supabase

انسخ ملف البيئة المثال:

```bash
cp .env.example .env
```

ثم ضع مفاتيح Supabase الخاصة بك:

```env
SUPABASE_URL=https://PROJECT_REF.supabase.co
SUPABASE_ANON_KEY=...
SUPABASE_SERVICE_ROLE_KEY=...
SUPABASE_BUCKET=place-photos
```

ثم افتح ملف:

```text
supabase_schema.sql
```

ونفّذ محتواه داخل SQL Editor في Supabase.

## تنبيه مهم قبل الرفع إلى GitHub

لا ترفع هذه الملفات:

- `.env`
- `config.json`
- أي خزنة شخصية أو ملفات مذكرات خاصة.

تمت إضافة `.gitignore` لمنع رفعها تلقائياً.

## بنية المشروع

```text
app.py                      الخادم المحلي وواجهات API
static/index.html           الواجهة العربية المتجاوبة
static/manifest.webmanifest ملف PWA
static/sw.js                Service Worker
static/icon.svg             أيقونة التطبيق
supabase_schema.sql         جداول Supabase
.env.example                مثال مفاتيح البيئة
config.example.json         مثال الإعداد المحلي
```

## الخصوصية

هذا التطبيق مخصص للاستخدام الشخصي. إذا أردت نشره على خادم عام، يجب إضافة حماية أقوى من مجرد رمز دخول محلي.
